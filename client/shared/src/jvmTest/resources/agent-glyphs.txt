# Every codepoint the terminal face must carry, and why.
#
# A browser has no system font behind Skia and a FontFamily of loaded fonts resolves to exactly
# one typeface, so a codepoint terminalmono lacks is tofu that nothing can supply. This file is
# the list of codepoints that must never be tofu, and TerminalFontCoverageTest is what enforces it.
#
# Measured, probe #270. Union of three corpora:
#   * every pane of a live herdr, read over pane.read while agent harnesses were working in them
#     -- the only instrument that sees render-time chrome at all
#   * 163 Claude Code transcripts under ~/.claude/projects (490M characters)
#   * 14 codex sessions and 56 gemini sessions (118M characters)
#
# Kept: non-ASCII, exactly one column wide, and not a letter of a script. That is the class the
# face is built for. Script letters (CJK, Hangul, Devanagari) and two-column glyphs are out of
# scope by design and go down the fallback path probe #214 built for them.
#
# A harness BINARY is not a usable instrument and was rejected: its non-ASCII is dominated by
# embedded Unicode character-property tables (NKo, Syriac, Armenian) that never reach a screen.
#
# Regenerate the face with `python3 tools/terminalmono.py --write` after adding a row here.
#
