
  terminal control sequences with columns Sequence, Name, and a third column What it does
  holding a full sentence of at least fifteen words each so the rows are long. Put one short
  sentence of prose before the table.

● These six sequences cover the cursor, screen, and mode changes a terminal client leans on
  most.

  ┌─────────────────┬────────────────────┬───────────────────────────────────────────────┐
  │    Sequence     │        Name        │                 What it does                  │
  ├─────────────────┼────────────────────┼───────────────────────────────────────────────┤
  │                 │ Erase in Display   │ Clears every character cell in the visible    │
  │ ESC[2J          │ (all)              │ screen area while leaving the cursor exactly  │
  │                 │                    │ where it was sitting before the call.         │
  ├─────────────────┼────────────────────┼───────────────────────────────────────────────┤
  │                 │ Cursor Position    │ Moves the cursor to row one, column one of    │
  │ ESC[H           │ (home)             │ the current screen, which is the conventional │
  │                 │                    │  starting point for a full repaint.           │
  ├─────────────────┼────────────────────┼───────────────────────────────────────────────┤
  │                 │ Alternate Screen   │ Switches the terminal to a separate screen    │
  │ ESC[?1049h      │ Buffer             │ buffer, saving the primary buffer so a        │
  │                 │                    │ full-screen program can restore it on exit.   │
  ├─────────────────┼────────────────────┼───────────────────────────────────────────────┤
  │                 │ Hide Cursor        │ Makes the text cursor invisible so that a     │
  │ ESC[?25l        │ (DECTCEM)          │ redraw does not show it skipping across the   │
  │                 │                    │ screen as cells are written.                  │
  ├─────────────────┼────────────────────┼───────────────────────────────────────────────┤
  │                 │ Device Status      │ Asks the terminal to reply on its input       │
  │ ESC[6n          │ Report             │ stream with the cursor's current row and      │
  │                 │                    │ column, letting a program discover position.  │
  ├─────────────────┼────────────────────┼───────────────────────────────────────────────┤
  │                 │ Set Foreground     │ Sets the foreground colour of subsequent text │
  │ ESC[38;2;R;G;Bm │ Colour             │  to an exact twenty-four-bit RGB value rather │
  │                 │ (truecolour)       │  than a palette index ch                      │
  └─────────────────┴────────────────────┴───────────────────────────────────────────────┘
